# Portfolio

The personal portfolio of Vadym, a front-end developer. It is a single page with a dark cyberpunk design, made with Next.js and Tailwind CSS.

## Setup

Use yarn 1. Do not use npm, because it makes a second lock file.

```bash
yarn install
yarn dev    # http://localhost:3000
```

## Design

The Figma design is the source of truth.

Mobile and desktop differ in structure, not only in size. Before a layout change, check both frames.
